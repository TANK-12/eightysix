### The 7 failures, with the cause and the fix (all fixed in part 2; see "Part 2" above)
1. `test_registry.gd` does not compile: `var colour_keys := Registry.entry(...)["colors"].keys()` has no
   inferable type. Fix: `var colour_keys: Array = ...`.
2. `test_controls.gd` does not compile: `var fire_pad := Controls.bindings(...)["pad"]`. Fix: `var fire_pad: Array = ...`.
3. `test_ui.gd:test_themes_switch_live`: the test still asks for stylebox type `"MenuButton"`. The theme
   variation was renamed `MainMenuButton` (MenuButton is a built-in Godot class and cannot be a variation).
   Fix the test string.
4. `test_graphics.gd`: the Low preset says `resolution_scale` 0.67 but the slider step is 0.05, so it snaps to
   0.65. Fix: set Low to 0.65 in `data/graphics_presets.json` and the test; also make
   `test_presets_cover_every_preset_setting` assert `sanitise(value) == value` so this cannot recur.
5. `test_bot.gd:test_frame_stats`: the test expects the 1% low to be 20 fps, but `frame_stats` takes the
   99th-percentile frame (60 fps with 1 slow frame in 100). Fix `Bot.frame_stats`: 1% low = the average of the
   worst 1% of frames (at least one frame), which is the usual definition.
6. `test_physics.gd:test_charge_jump_then_no_air_control`: sideways velocity changed 3.2 m/s mid-air.
   Cause (reasoned): legs count as grounded whenever their ray hits within `rest + ray_margin_m` (1.2 m), so
   right after the 0.18 s spring cut-off the mech is still "on the ground" and `_drive` applies the strafe.
   Fix in `scripts/mech/standin_mech.gd`: a leg is loaded only when the hit is within the rest length plus a
   few centimetres; keep the long ray for the step visuals only; after a launch stay airborne until a leg is
   actually compressed again.
7. `test_physics.gd:test_bench_mode_is_slow`: moved 11.3 m in 3 s in bench mode (cap should be about
   0.95 m/s, so under 3 m). Cause **not found yet**: `_drive` caps `top/back/side` with `_bench_speed_cap`
   when `bench_mode()`; check that `_bench_speed_cap` is finite after `setup()` (print it), and that the
   distance is not mostly the settle drop (the test measures 3D distance; measure the flat distance).

Also: `graphics.gd` logs "Error calling deferred method `_apply_new_node`: Cannot convert argument 1 from
Object to Object" when a node is freed before the deferred call runs (tests free nodes quickly). Fix: take
`node: Variant` and check `is_instance_valid` first. The "Parse JSON failed" line in the log is expected (a
test feeds it bad JSON on purpose).
