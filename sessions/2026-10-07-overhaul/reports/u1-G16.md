Static changes reach the Forge window on the next page reload. The backend

## Media (commits 2fc302e, follow-up ba3e85e)

What changed (full list in `apps/media/WIP.md`, top section):
- Start-up: the page ran `loadSettings().then(loadLibrary)` once. If the
  server was not up yet, it stayed blank and threw an uncaught error. Now
  there is a calm note with a Try again button, and a retry through
  `ForgeIdle.poll` that waits 2 s, then doubles up to 30 s. It only runs
  while the page is shown and stops once loaded.
- Library: loading, empty, no-match and error notes instead of a blank
  card. Only one scan runs at a time. Search waits 120 ms after typing stops.
- Download: one request per click (a double click used to start two jobs).
  Failed lookups and Stop failures show a toast. "Up to" is clamped to 1-500.
- Backend bounds: `limit` must be 1-500 (-5 started a real yt-dlp search).
  `kind` must be audio or video. At most 500 urls, 50 folders, volume 0-100,
  no NUL bytes in paths (`/api/file` with one was a 500), and size caps on
  text fields. A junk settings.json falls back to the defaults.
- Looks: 180 ms tab fade. Under 900 px the tabs get their own row (at 760
  px the header ran 98 px past the edge and pushed Full screen off). Thin
  themed scrollbars, placed at the window edge.

Tests: pytest 35 pass (21 new in `tests/test_u1_robustness.py`, one added after the critic). black is
clean; pyright shows 0 errors before and after.

## MediaForge (commits b6b51ba, follow-up b5b9a43)

What changed (full list in `apps/mediaforge/WIP.md`, top section):
- Security: `/api/dedupe/thumbnail?path=/etc/passwd` returned the file. The
  route served any readable file on disk to anything that could reach the
  port. It now serves only the page images listed by a pending Duplicate
  Slayer review. Anything else is a 404.
- Settings: `POST /api/settings` checks each value's type, so
  `{"jan_base": 5}` is a 400. A saved `jan_base: 5` in settings.json used to
  crash start-up; `load_settings` now drops wrong-typed values.
- `/api/subtitles/probe` on a missing file is a 404 ("scan the folder
  again"). Before, it reported "1 audio / 1 subtitle tracks" for a file that
  does not exist. Storage search needs a finite `min_mb`, and `limit` is
  clamped.
- Page: one request per click (`onClickOnce` on 21 buttons). Every fetch
  checks `res.ok`. A page-wide catcher turns a failed request into a calm
  toast ("MediaForge's server is not answering"). Start-up goes through
  `boot()`: if the server is not up yet, a banner appears over the panels and
  `ForgeIdle.poll` retries, slowing from 2 s to 30 s and resting while
  hidden. The banner clears by itself. The name-check `setInterval` became
  `pollJob`.
- Copy: the brand reads MediaForge. "KILL" became "Kill", and "Jan OFFLINE"
  became "Jan is offline: open Jan and start its local API server".
- Looks: thin themed scrollbars, panel fade, and room at the bottom so the
  Close app / Full screen pills do not cover the last card.

Tests: pytest 21 pass (new `tests/test_u1_robustness.py`, 17 cases counting parameters, with the critic follow-up). black
is clean. pyright on the touched files went from 54 errors at HEAD to 40,
none new; `Job.result` is now typed `Any`.

## Shared changes recommended

- `shared/forge.js` `pollJob` should back off on errors and pause while the
  page is hidden, like `ForgeIdle.poll`. Right now each app adds its own.
- A shared thin, themed scrollbar style in `shared/forge.css`. Every swept
  app has been adding the same few lines.
- A shared `onClickOnce` helper. Both apps here needed the same guard.
- `errText` in `shared/forge.js` should join a list-shaped `detail` (FastAPI
  422) into one line; today it returns the array and toasts "[object Object]".

## Assumptions

- Media and MediaForge settings files on the scratch servers used a temporary
  HOME and data folder. Emerson's real settings were never read or written.
- For the thumbnail route, "a page of a pending review" means any path
  listed in the groups of a job whose result says `needs_review`. That is
  everything the review UI asks for.
