## PulseForge (commit 2af9e5a)

What changed (full list in `apps/pulseforge/WIP.md`, top section):
- Data safety (backend): `DELETE /api/projects/%2E%2E` deleted all of
  `~/PulseForgeData`. I confirmed it on the scratch copy, which held only
  throwaway data. Any `.` / `..` path segment under `/api/` is now a 400
  (`RequestGuard` in `web_app.py`). `projmod.delete` only removes a folder
  inside `projects/`, and dots-only names get their own folder. Duplicate /
  template could overwrite another project with the same name; copies now
  always get a new folder.
- Robustness (backend): NaN / Infinity in any JSON body was a 500. In a
  project edit it was saved and bricked the project, so it could not be
  opened again. It is now a 400. A 5000-character name was a 500; names are
  now capped at 300 (422) and folder names at 80. The fuzz of every write
  route went from 76 answers of 500 to 0.
- Page: the queue poll backs off while the server is down and says so
  (breaker item 6). A failed start shows a calm card and retries by itself.
  Render, Preview, Make, Create, uploads and the other buttons send one
  request per press (a double click queued the same render twice). Project
  names and pre-flight text are escaped. The Simple preview's broken-image
  icon is replaced by a calm 16:9 note. A looping or silent preview video
  pauses while hidden. Scrollbars are thin and themed, and tabs fade in over
  180 ms.

## shared/ recommendations
- `forge_idle.js` could offer a small `ForgeIdle.onChange(fn)`. PulseForge
  and AI Studio both hand-roll `visibilitychange` + `forge-visible` listeners
  to pause media.
- A shared "one press, one request" helper (`oneAtATime` in PulseForge's
  index.html) would suit every app's submit buttons.
- A shared ASGI guard for `.`/`..` path segments and NaN bodies would help
  every FastAPI app with `{slug}` routes over folders.

## Assumptions
- Audible media (a render you play to listen) keeps playing when PulseForge
  is hidden; only looping or muted videos pause.
- Creating a project with a name already in use still reopens that project,
  as before. It never wiped the project, so I left it alone.
- The floating Close app / Full screen pair overlaps the bottom-right corner
  only standalone; inside Forge the hub carries them, so I left it.
