## What changed, in short
- Codec Lab: upload names cannot leave `clips/uploads/`, never replace a
  clip, fit in 255 bytes and cannot collide; run requests are checked field by
  field and param by param against the strategy schema (422, nothing queued);
  the memory guard's advice is shown; every name is escaped; the poll rests
  while hidden and backs off while the server is away; failed runs show why;
  the comparison videos actually play now (an old seek loop kept them at 0 s
  and restarted them while hidden) and pause while hidden; no sideways scroll
  at 760 px; empty/loading/error states, thin scrollbars, a 200 ms fade.
- Codec Player: the `.acv` header and the size inside each strategy's stream
  are both checked against the memory budget before decoding (a 1.3 kB file
  could ask for 250 GiB); malformed files are 422s and leave no folder; one
  open per drop; the video pauses while hidden; long errors wrap.
