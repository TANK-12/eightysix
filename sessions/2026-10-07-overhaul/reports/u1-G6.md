## Emberfield — commits d68f95d (sweep), 1805b10 (critic follow-up)
Full list of changes and what is verified: `apps/emberfield/WIP.md` (new file;
the app's long record stays in `MANIFEST.json` + `manifests/`). In short:

- One frame loop (`kickLoop()`): a double click on Begin, or pause+resume within
  one frame, used to start extra loops (game at 2x-4x speed until reload).
- No double submits: Begin/Continue (`S.starting`), cave mouth and doors
  (`S.travelling`). Two quick presses at the cave mouth used to lose the valley
  for the session.
- Calm errors: `api()` helper; boot failure retries by itself (2-30 s backoff,
  paused while hidden) with a Try now button; toasts for Begin, Continue, wilds,
  doors, Settings; Save & leave stays put if the save failed; failed quiet saves
  are announced; a 500 no longer reads as "saved".
- Rest: pause (and hub-hidden / tab-hidden) suspends the AudioContext and stops
  the tutorial interval; waking from sleep while off screen opens the pause
  screen. Already in place before: hidden -> pause screen, no rAF.
- Looks: no overlap of tutorial / key hint / hotbar at 760-1500 px (two media
  queries), thin styled scrollbars on the menu veil (incl. -webkit-), menu cards
  ease in (opacity/transform 180 ms), hotbar slot lift slides, reduced motion.
  The game keeps its own warm palette (it never used forge.css tokens; a game's
  look was left as is on purpose: "if something works fine, do not change it").
- Backend: settings type-checked and clamped (`config.clean_settings`);
  `{"heavy_cores":"abc"}` used to brick `/api/capabilities` and so the boot.
  `Cache-Control: no-cache` on every response, and `?v=2026-10-08` on the
  script tags: a stale cached `ui.js` paired with the fresh page never booted
  (seen in a reused Chrome profile during this sweep).
- Escaping of save names and server messages put into innerHTML.

## Shared/ recommendations
- Other apps serve static JS through StaticFiles without Cache-Control too; a
  shared middleware (or a `?v=` stamp helper) would stop stale-script boots
  everywhere after an edit.
- Emberfield does not use `forge_power.js`: a game's frame rate was left alone
  for looks; if a "reduced" tier should cap game fps, that needs a shared
  helper the games can call.
