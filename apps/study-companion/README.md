# Study Companion

A Jan-backed tutor grounded in your own course material, plus a deterministic
question bank that needs no LLM at all. Port 8443, order 20. See
`forge_app.json`'s `manifest` for the short version.

## Why two separate paths

1. **The bank** (`data/<course>/questions/*.jsonl`) is plain arithmetic —
   generated once by a Python script, verified correct, works instantly with
   Jan off or even slow. This is the answer to "the practice questions aren't
   enough": a large, always-available, exam-realistic set.
2. **Jan chat and quiz generation** read the raw lecture text in
   `data/<course>/*.txt` and answer *only* from it, per the system prompt in
   `web_app.py`. This is for "explain this to me again" / "quiz me on
   something new" in your own words — genuinely generative, so it needs Jan
   running and can be slower or occasionally malformed (handled: a quiz reply
   that doesn't parse as valid JSON lines is reported as an error, never
   silently guessed at).

## Adding a course

Drop a folder under `data/<yourcourse>/` with `.txt` sources (pdftotext -layout
output works well — no PDF parsing happens in this app) and optionally a
`questions/` subfolder of `.jsonl` files following the schema documented at
the top of `data/MATH1014/questions/generate.py`. Nothing else needs wiring —
`/api/courses` discovers folders under `data/` the same way Forge discovers
apps under `apps/`.

The JSONL schema is deliberately one-object-per-line rather than one big JSON
array, specifically so a small local model asked to write more questions only
has to get a single line right at a time — a bad line is discarded, not a
syntax error that invalidates everything after it (`_load_bank` in
`web_app.py` does exactly that).

## MATH1014 (Topics 1–6, the test on 16–19 Sep 2026)

`data/MATH1014/` holds the extracted text of the Topic 1–6 lecture slides
(Topic 7, Differentiation Applications, is intentionally excluded — the
outline says the test covers Topics 1–6 only) plus `questions/bank.jsonl`: 108
hand-verified questions generated by `generate.py` (18 per topic except T1 at
20 and T2 at 16), covering: domain/range, linear/quadratic functions,
rational-function asymptotes, piecewise evaluation, trig amplitude/period,
solving trig equations, degree/radian conversion, solving exponential and log
equations, combining logs, direct-substitution and 0/0 limits, limits at
infinity, and the power/chain rules. Re-running `generate.py` overwrites
`bank.jsonl` with a fresh but still-seeded (reproducible) batch; anything
Jan generates via `/api/quiz` is appended to a separate `bank_jan.jsonl` so it
never touches the hand-verified file.

There is also a standalone claude.ai Artifact covering the same six topics
with its own randomized practice generators, a printable two-page cheat sheet,
and the exact test-day logistics from the outline — built the same night as
this app, for immediate use without Jan or a Forge launch.

## Running it standalone

```bash
cd ~/Forge/apps/study-companion
FORGE_SHARED_DIR=~/Forge/shared .venv/bin/python -m uvicorn web_app:app --host 127.0.0.1 --port 8443
```

Then open <http://127.0.0.1:8443>. Jan must be running at `http://127.0.0.1:1337/v1`
(or set `JAN_BASE_URL`) for the Chat and Quiz tabs — the Question bank tab
works regardless, and the header dot / status text tell you plainly which
state you're in rather than failing silently.

  bug found and fixed (a power-rule question with exponent 1 showed an
  unsimplified `x^0` in the derivative).
- The frontend's expression compiler (used for the `PLOT` chat directive) was
  extracted and run under `node` directly against `1/(x+1)`, `x^2 - 4`,
  `sin(2*x)`, `sqrt(16-x^2)`, `3*e^(4*x)`, `ln(x+1)`, `log(x)`,
  `tan(x)+cos(x)` — all correct. A real bug was caught and fixed here too:
  chaining separate `.replace()` calls for each function name meant the `ln(`
  replacement's own output (`Math.log(`) then matched the *next* `log(`
  replacement, producing `Math.Math.log10(`. Fixed by doing all function-name
  substitution in one alternation-based pass.
